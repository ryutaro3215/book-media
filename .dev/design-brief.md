## デザインの基本方針

**読みやすさの設計は note を基準とし、識別子は「5冊のカード」と「OGP画像」だけで作る。**

根拠（requirements.md「最優先事項: UI/UXの質」より）:
- 競合 Five Books は17年・1,700本のアーカイブを持ち、**後発が量で勝つ経路はない**。勝てるのは1記事の体験の質のみ
- 一方 note の見た目は「現代的なブログの標準形」であり、そのまま真似ると読みやすさは得られるが差別化は得られない
- したがって **土台（本文組版・余白・ナビゲーション）は徹底的に無装飾にし、5冊のカードだけが際立つ構造にする**

## デザイントークン（承認済み・2026-08-04）

### 配色（3色構成 + 副次色）
| 用途 | HEX | 備考 |
|---|---|---|
| 背景 | `#FFFFFF` | 書影の白背景と衝突しない |
| 本文 | `#292929` | 純黒はコントラストが強すぎるため使わない |
| 副次テキスト（出版社名・刊行年・日付） | ~~`#787878`~~ → **`#767676`** | **2026-08-05 修正。** `#787878` は白背景でコントラスト比 4.42:1 となり、非機能要件の WCAG AA（4.5:1）を下回っていた。`#767676` は 4.54:1。見た目の差はほぼ判別できない |
| 罫線・区切り | `#E6E6E6` | |
| **アクセント** | **`#2F4A3F`（墨緑）** | **リンクとメール登録ボタンのみに使用。** 見出しや装飾には使わない |

書評・学術系サイトの定番色（赤・青）を外すことで、色だけでも識別できる状態にする。

### タイポグラフィ
| 項目 | 値 |
|---|---|
| 和文書体 | **Zen Kaku Gothic New**（見出し・本文とも。無料・セルフホスト可） |
| 数字・欧文 | 同上に含まれる欧文、または必要に応じて等幅の数字 |
| 本文サイズ | 16px（モバイル）/ 17px（デスクトップ） |
| 行間 | **1.9**（noteの読みやすさの正体。ここを詰めない） |
| 本文カラム幅 | 最大 **660px**（全角約38字。requirements の「35〜45字」に収まる） |
| 見出しの階層 | h2 = 本文の1.5倍・太字 / h3 = 1.2倍。**サイズと太さだけで階層を作り、色や罫線で飾らない** |

### 余白
- 本文の段落間: 行間の1.5倍以上
- セクション間: 64px以上（モバイル 48px）
- **5冊カードの間隔は本文の段落間より明確に広く取る**（カード群が独立したブロックとして読めるように）

### トーン
静かで、余計な装飾がなく、長時間読んでも疲れない。学術的だが古めかしくない。
**「デザインされている」と気づかせず、読み終わった後に「読みやすかった」とだけ残るのが成功。**

## 書影の扱い（設計上の最重要制約）

書影は**取得できる本とできない本が混在する**（学術書は欠損率が高いと想定。実測進行中）。

**したがって「書影あり」「書影なし」が同じ枠に収まり、混在しても破綻しない設計が必須要件。**

- 全カードで**同一の縦横比の枠**を用意する（推奨: 高さ基準で統一。書籍は判型がばらばらなため、幅ではなく高さを揃える）
- 書影がある場合: 枠内に画像を配置
- 書影がない場合: 枠内に**書名を組んだ文字だけの面**を表示する（ビルド時に生成）
  - グレーの箱・「No Image」等は**絶対に使わない**。手抜きに見えた時点でこのプロダクトの価値が消える
  - 文字だけの面は「そういう装丁の本」に見えることを目標とする（岩波文庫等に実在する形式）
- 両者に共通の枠線・余白・影を与え、**一つのグリッドとして成立させる**

## プロンプト

### 1. 記事ページ

```
学術書の選書メディアの「記事ページ」を作成してください。

- Goal: 専門家1人が選んだ5冊とその選書理由を、最後まで気持ちよく読み通させること。
  読者が「この選者を信頼できる」と感じ、選者本人が「これなら共有したい」と思う品質にすること。

- Audience: 専攻外の分野に入門したい大学院生・学部生、および知的関心で学術書を読む社会人。
  デバイス: モバイル優先（Xからの流入が主）。デスクトップにも対応。

- Layout: 上から順に
  1. 記事ヘッダー（分野名 / 記事タイトル / 選者名 / 所属 / Xアカウントへのリンク）
  2. 導入文（選者の紹介と、この5冊で何が見えるかの短い文章。3〜5段落）
  3. 5冊のカード（01〜05。各カードは「書影の枠 + 書名 + 著者 + 訳者 + 出版社・刊行年 + 選書理由の本文」）
  4. 記事末尾のまとめ（1〜2段落）
  5. メール登録フォーム（1行の説明 + メールアドレス入力 + ボタン）
  6. フッター（サイト名 / このサイトについて / 出典・書誌情報の注記）

- Content:（以下はデザイン検証用のダミーデータ。実在の記事ではない）
  分野名: 行動経済学
  記事タイトル: 山田太郎が選ぶ、行動経済学を学ぶための5冊
  選者: 山田太郎 / ○○大学 経済学部 教授 / @yamada_t
  1冊目: ファスト＆スロー（上） / ダニエル・カーネマン / 村井章子 訳 / 早川書房・2014
  2冊目: 選択と希少性の経済学 / センディル・ムッライナタン / 早川書房・2015
  3冊目: 実践 行動経済学 / リチャード・セイラー / 日経BP・2009
  4冊目: 経済学は人びとを幸福にできるか / 宇沢弘文 / 東洋経済新報社・2013
  5冊目: 行動経済学の逆襲 / リチャード・セイラー / 早川書房・2016
  各書籍の選書理由: 300〜600字程度の本文（ダミーテキストで可）

- 制約:
  - 配色は3色のみ: 背景 #FFFFFF / 本文 #292929 / アクセント #2F4A3F
    （副次テキスト #787878、罫線 #E6E6E6 のみ追加可）
  - アクセント色はリンクとメール登録ボタンにしか使わない。見出しや装飾に使わない
  - 和文書体は Zen Kaku Gothic New。本文16〜17px、行間1.9、本文カラム最大660px
  - 見出しの階層はサイズと太さだけで表現する。色・罫線・背景色で飾らない
  - 5冊のカードは、書影がある本とない本が混在しても破綻しない設計にすること。
    書影の枠は全カードで高さを統一し、書影がない場合は書名を組んだ文字だけの面を表示する。
    グレーの箱や「No Image」表示は使わないこと
  - カードの番号（01〜05）は視覚的なリズムを作る要素として使ってよい
  - 影・角丸・グラデーション・アイコンは最小限にする。装飾で情報量を増やさない
  - CTAはメール登録の1種類のみ。他のボタンを置かない
```

**生成後の確認観点**
- [ ] 本文カラムが広すぎないか（全角38字前後に収まっているか）
- [ ] 行間が1.9を維持しているか（詰まっていたら「行間を1.9に戻して」）
- [ ] アクセント色が見出しや装飾に漏れていないか
- [ ] 5冊のカードが本文より明確に目立ち、かつ統一されたグリッドに見えるか
- [ ] 選者のXリンクがヘッダー内で見つけやすいか
- [ ] モバイル幅でカードが崩れないか

**修正プロンプト集**
- 装飾過多になった場合: 「影・角丸・背景色を全て取り除いてください。区切りは #E6E6E6 の細い罫線と余白だけで表現してください」
- アクセント色が漏れた場合: 「#2F4A3F はリンクとメール登録ボタンにのみ使用してください。見出し・アイコン・罫線からは取り除いてください」
- カードが弱い場合: 「5冊のカードの上下の余白を本文の段落間の2倍以上にして、カード群が独立したブロックとして読めるようにしてください」
- 書影なしの表現が手抜きに見える場合: 「書影がない書籍の枠には、書名を大きく組んだ文字だけの面を表示してください。グレーの塗りつぶしや『No Image』は使わないでください」

### 2. 5冊カード（単体設計）

```
書籍1冊分のカードコンポーネントを、以下の2つの状態で作成してください。

- Goal: 書影がある本とない本が縦に並んでも、一つの統一されたグリッドとして成立させること。
  読者が5冊を「1セットの推薦」として認識できること。

- Audience: 記事ページと同じ（モバイル優先）

- Layout: 各カードは以下を含む
  - 通し番号（01〜05）
  - 書影の枠（全カードで高さを統一）
  - 書名（最も大きい要素）
  - 著者名 / 訳者名
  - 出版社・刊行年（副次テキスト）
  - 選書理由の本文（300〜600字）
  - **「この本が知られていない理由」（本文とは視覚的に区別された短い一段落）**
    ※ 2026-08-05 のコンセプト変更で追加。このメディアの核となる情報なので、
      選書理由の中に埋もれさせず、独立した要素として読めるようにすること

- Content:（ダミーデータ）
  状態A（書影あり）: 01 / ファスト＆スロー（上） / ダニエル・カーネマン / 村井章子 訳 / 早川書房・2014
  状態B（書影なし）: 02 / 選択と希少性の経済学 / センディル・ムッライナタン / 早川書房・2015

- 制約:
  - 状態Aと状態Bを縦に並べて表示し、並んだときに違和感がないことを確認できる形で出力すること
  - 状態Bの書影枠には、書名を大きく組んだ文字だけの面を表示する（実在する文字中心の装丁のように見せる）
  - 配色・書体は記事ページと同一
  - 書影の枠は高さを統一する（書籍は判型がばらばらなため、幅を揃えると縦位置が揃わない）
```

**生成後の確認観点**
- [ ] 状態Aと状態Bを並べたとき、Bが「画像の欠落」ではなく「そういう装丁」に見えるか
- [ ] 書名が最も目立つ要素になっているか
- [ ] 選書理由の本文が読みやすい行長を保っているか

### 6. 文書ページ共通テンプレート（このサイトについて / 取材依頼 / プライバシーポリシー / 404）

```
静的な文書ページの共通テンプレートを作成してください。

- Goal: 記事以外の情報（運営者について、連絡先、方針）を、記事ページと同じ読みやすさで伝えること。

- Layout:
  1. ページタイトル（h1）
  2. 本文（見出しと段落のみ。記事ページと同じ組版）
  3. フッター（記事ページと共通）

- Content:（「このサイトについて」の構成例。実文はオーナーが後で執筆する）
  h1: このサイトについて
```

## Claude Design での手順

1. claude.ai/design で新規プロジェクトを作成する
2. 本ブリーフの「デザイントークン」セクションを**最初に貼って宣言する**
3. プロンプトを**1画面ずつ**貼る（一度に全部貼らない）。順序は
   **記事ページ → 5冊カード → OGP画像 → トップ → メールフォーム → 文書ページ共通テンプレート → 選者ページ → 分野別アーカイブ**
   - **記事ページと5冊カードが最重要。ここに最も時間をかける**
   - 文書ページ以降は「記事ページのトーンを引き継ぐ」ことが目的なので、**時間をかけない**。凝ると全体の統一感が壊れる
4. 修正はインラインコメントで具体的に指示する（「ここを8px詰める」等）。上記の修正プロンプト集を活用する
5. 完成後: standalone HTML でエクスポートし、`design/` 配下に配置する
