# public/thumbnails/ — 記事サムネイルの置き場

トップページの記事カード（236×150px）に使う画像を置く。

## ファイル名

`<記事の slug>.jpg`。例: `yamada-behavioral-economics.jpg`

`.jpeg` / `.png` / `.webp` も認識するが、原則 `.jpg`。
slug は記事の frontmatter の `slug` と完全一致していなければならない。

## 用意しなくてよい

置かなかった場合は、**その記事のOGP画像（`/og/<slug>.png`）が自動で使われる**。
OGP画像は記事ごとにビルド時に生成されるので、何もしなくてもサムネイルは表示される。

記事を出すたびに画像制作が発生すると、記事を出し切ること自体の障害になるため、
用意は任意にしてある。**まずは記事を出すことを優先すること。**

## 使い分け

- 通常: 何も置かない（OGP画像が使われる）
- 特定の記事だけ見た目を強くしたい: その記事の分だけ置く

推奨サイズは 472×300px 以上（2倍解像度）。表示は `object-fit: cover` で切り抜かれる。
