# 選者応募フォーム

その領域に詳しい方に、その領域を学ぶための本を挙げていただいています。
いただいたご応募は、基本的に掲載させていただく方針です。

お名前は本名でなくても、ご所属の記載がなくても構いません。
掲載させていただく場合は、公開前に必ず原稿をお送りし、ご本人に確認していただきます。
入力は5〜10分ほどです。

## あなたについて

お名前 *
記事に表示されます。本名でなくても構いません（ふだんお使いのお名前で結構です）。

メールアドレス *

ご所属

専門分野・関心のある領域 *

この本を薦められる背景を、一言だけ教えてください *
肩書きや形式は問いません。「〇〇を15年読み続けている」「Xで書き続けている」「仕事で扱っている」程度で十分です。うまく書けない場合は空欄でも構いません。こちらで下書きしてご確認いただきます。

X（旧Twitter）のアカウント
任意です。ご記入いただいた場合のみ、記事からリンクします。@ は付けずにIDだけご記入ください。

アイコン画像をアップロードしてください（ファイルアップロード）
任意です。記事と選者ページに表示されます。顔写真でなくても構いません（イラスト・アバターなど）。ファイル形式は jpg / png / webp、1ファイルまで。正方形に切り抜かれますので、200×200px 以上の画像をおすすめします。ご提供がない場合は、お名前の頭文字を丸く表示します。
