# トピック分類（大トピック / 小トピック / タグ）

`docs/topic.md`（学問の一覧）から抽出し、手で調整したもの。
**このファイルは人が読むための一覧**で、ビルドで使う語彙は
`src/data/topics.json` / `src/data/tags.json`。

## 構造

| 階層 | 役割 | 例 | 管理 |
|---|---|---|---|
| **大トピック** | 学問の大分類 | 数学 / 経営学 | `topics.json`（語彙を閉じる） |
| **小トピック** | その下の分野 | 統計学 / 経営戦略論 | `topics.json`（大トピックに紐づく） |
| **タグ** | さらに細かいもの | 多変量解析 / 作用素環論 | `tags.json`（必要なら追加できる） |

**大トピックを選ぶと小トピックの候補が絞られる。** それより細かいものはタグで足す。

**「人がすすめる本」だけは軸が違う。** 他の31件は学問の分野だが、これは
**誰がすすめたか**で切ったもので、小トピックが 大学・研究者 / 俳優・声優 /
芸人 … となる。大学の推薦図書リストや雑誌の企画のように分野をまたぐ選書は
学問の軸に置けないため、受け皿として1つだけ別軸を持たせた。
`topic` は1記事に1つなので、分野が絞れる記事は分野側に置く。

**各大トピックの先頭には「〇〇全般」がある**（`数学全般` など）。どの小トピックにも
当てはまらない記事に使う。下の一覧には元データ由来の分野だけを載せてあるので、
「〇〇全般」は現れないが、`topics.json` には31件すべてに入っている。

## 元データからの変換で行ったこと

- `# 生物学（続き）` `# 医学（続き）` は分割されていただけなので**統合**した
- `## 見出し` と第1階層の `- 項目` は**同じ役割で混在**していたため、どちらも小トピックとして扱った
- 「（→詳細は…を参照）」のような注記は除去した

### 各分野の「〇〇史」を、それぞれの大トピックへ移した

元データでは経営史・数学史・法制史などがすべて歴史学に入っていたが、
**それぞれの学問の一部**として扱う方が記事の分類として自然なため移動した。

```
経営史 → 経営学    数学史 → 数学    法制史 → 法学
経済史・経済思想史 → 経済学          政治史・政治学の歴史 → 政治学
文学史 → 文学      美術史・音楽史 → 芸術  技術史 → 工学  ほか
```

**歴史学に残したもの**: 史学史・文化史・精神史・女性史・郷土史・歴史哲学・
世界史・地域史などの**歴史学そのものの方法・時代・地域**に関わるもの。
あわせて以下2つも歴史学に置いた。

- **科学史** — 特定分野の歴史ではなく「科学を対象とする歴史研究」であるため
- **文献学** — 古典研究・書誌学寄りであるため

### 「統計学」を追加した

元データに**統計学が無かった**（統計力学・生物統計学・経済統計学・人口統計学のみ）。
**数学の小トピック**として追加し、下位にタグ候補を置いた。
